# Le Choix de Sophie — Site vitrine

Projet [Vite](https://vitejs.dev).

## Démarrer

```bash
npm install
npm run dev        # serveur de développement
npm run build      # version de production (dossier dist/)
npm run preview    # prévisualiser le build
```

## Notes

- Les photos de produits pointent vers des sites de fournisseurs (melissanepton.com, cream-clothing.com) — à remplacer par vos photos officielles avant la mise en ligne (dossier `public/assets/`).
- Couleurs et typographies selon la charte graphique 2026 : Noir profond #141416, Or champagne #C9A962, Or foncé #B8934A, Ivoire #F3ECDF, Blanc cassé #FFFDF8 · Cormorant Garamond + Jost.
